# Native AI reports

The detailed acquisition and interpretation protocol is owned by `aieo-visibility`: load it, then its `references/native-consoles.md`. GSC Search Generative AI has a real native UI report and export; an equivalent dedicated API endpoint/filter is not confirmed in the checked Search Analytics API. Current wrapper fields do not prove such support. Read-only verify the exact property and report availability; never change AI inclusion control during an audit.
